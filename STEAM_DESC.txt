[h1][B42] RV Interior Manager[/h1]

A companion admin panel for [b]PROJECT RV Interior[/b] (and its expansion mods). Gives server admins full visibility and control over every vehicle-to-room assignment in the save, with real-time position tracking, sorting, filtering, and manual assignment tools.

[h2]Features[/h2]

[h3]Admin Panel[/h3]
Open via the [b]RV Interior Manager[/b] button in the Admin Panel (admin/moderator only).

[b]Room Types tab — type list (left panel)[/b]
[list]
[*]One row per interior type with room dimensions (e.g. [i]8x4[/i]) and slot counts (total / available / occupied)
[*]Select a type to edit its compatible vehicle list on the right
[*]Search field to filter types by name
[*][b]Restore Default[/b] button resets all type overrides to the original mod values
[*]All changes are saved to [b]~/Zomboid/Lua/vehicles_type_changes.lua[/b] on the server — this file is outside the world save and [b]persists across world wipes[/b]
[/list]

[b]Room Types tab — compatible vehicles (right panel)[/b]
[list]
[*]Lists every vehicle script assigned to the selected type
[*]Each entry shows a status badge:
[list]
[*][b]Mod active[/b] (green) — the mod that provides this vehicle is installed on the server
[*][b]Mod not found[/b] (orange) — the script is in the list but the mod is not installed; players cannot use it
[/list]
[*]Add a vehicle by typing its script name ([i]Base.ScriptName[/i]) and clicking [b]Add[/b]
[*]Remove any vehicle with the [b]×[/b] button
[*]Changes take effect immediately — no server restart needed
[/list]

[b]Important:[/b] if a vehicle is removed from all type lists while it still has a room assigned, players can no longer enter that RV. The room stays reserved until an admin [b]Dissociates[/b] it from the context menu. The vehicle must be re-added to a type and re-associated before it becomes usable again.

[b]Cross-search panel[/b]
[list]
[*]Type part of any vehicle script name to instantly see every interior type it belongs to across all installed mods
[/list]

[b]Linked Vehicles tab[/b]
[list]
[*]Lists every vehicle that currently has an interior room assigned
[*]Columns: Vehicle ID · Name · Vehicle Position · RV Type · Room Position · Linked At · Last Enter · Last Exit
[*]Click any column header to sort ascending/descending; click again to reverse
[*]Hover over any cell to see the full untruncated value in a floating tooltip
[/list]

[b]Filter bar[/b]
[list]
[*]Search across: Name, Vehicle ID, RV Type, Room position, Vehicle position, Linked At, Last Enter, Last Exit
[*]Type any partial string to filter the list in real time
[*]Type [b]-[/b] to find records with empty fields (e.g. vehicles never entered)
[/list]

[b]Action buttons[/b] (all with tooltips)
[list]
[*][b]Teleport to Vehicle[/b] — teleports the admin to the vehicle's last known world position
[*][b]Teleport to Room[/b] — teleports the admin into the interior room
[*][b]Dissociate[/b] — frees the room assignment
[*][b]Force Idle Check[/b] — runs the idle room cleaner immediately instead of waiting for the next hourly cycle
[/list]

[h3]Context Menu (right-click a vehicle)[/h3]
Available to admins and moderators when right-clicking a supported vehicle from outside:
[list]
[*][b]Associate RV Interior[/b] — appears when the vehicle has no room assigned:
[list]
[*][b]Random room[/b] — assigns the next available slot automatically
[*][b]Choose room…[/b] — opens a picker with region filter (Main / Update 1 / Update 2), coordinate search, and a scrollable numbered list; confirm to assign a specific room
[/list]
[*][b]Dissociate RV Interior[/b] — appears when the vehicle has an assigned room; frees the slot
[/list]

[h3]Sandbox Options[/h3]

[b]Require Admin to Associate[/b] [i](Sandbox → RV Interior Manager → Require Admin to Associate Rooms, default: OFF)[/i]

When enabled, only admins and moderators can associate a room to a vehicle. Regular players cannot enter an RV that has no room assigned — they are blocked before the teleport happens and receive an on-screen message. They stay in the world until an admin associates the vehicle.

[b]Idle Room Cleaner[/b] [i](Sandbox → RV Interior Manager → Idle Cleanup Days, default: 0 = disabled)[/i]

Automatically dissociates rooms that have not been entered for the configured number of real-world days.
[list]
[*]Uses [b]Last Enter[/b] date as the reference; falls back to [b]Linked At[/b] if the vehicle was never entered
[*]Runs once on world load and every ~60 minutes during the session
[*]Every dissociation (idle or manual) is logged to [b]~/Zomboid/Lua/RVM/idle_YYYY-MM-DD_HH-MM-SS.txt[/b] — one file per server session, with full details (vehicle ID, name, type, room and vehicle positions, dates)
[/list]

[h2]Short FAQ[/h2]

[b]Game version:[/b] B42 Unstable (latest)
[b]Multiplayer:[/b] Yes
[b]Added midgame:[/b] Yes — pre-existing room assignments will show up in the panel immediately. Some fields (vehicle name, last position) will populate as vehicles are loaded into the world. The [b]Linked At[/b] date is the only field that cannot be recovered retroactively; it will be set to the first enter/exit event recorded after this mod is installed.
